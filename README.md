# Student Marks Manager

A menu-driven Python program to store student marks and report grades,
the topper and the class average. Built from scratch as a Python
basics practice project.

## What it does
- Add a student (name + marks)
- Show all students with grades (90+ A, 75+ B, 60+ C, 40+ D, else Fail)
- Show the topper
- Show the class average
- Handles an empty list without crashing

## Concepts used
Lists, tuples, tuple unpacking, functions and return values,
if/elif/else, while loops, break, enumerate, input validation.
